# Identity Analytics 3.x Release Notes

## IAP 3.6

**Release date: 2026-05-19**

### Prerequisites

IAP 3.6 requires `Descartes R6` and `Java 21`.

### New Features

#### Access360

* BWIPUAR-2510 Added support for custom messages on the IAP home page
* BWIPUAR-2505 Added account-related columns to the `access360analytics_group_Accounts` page

#### Performance

* BWIPUAR-2556 Improved performance of IAP views (Access360 and Reviews) with faster counters

#### Remediation

* BWIPUAR-2420 Enhanced the remediation follow-up dashboard for administrators

#### Reviews

* BWIPUAR-1166 Campaign Manager now preserves page context
* BWIPUAR-2320 Added support for Unstructured Data Reviews
* BWIPUAR-2491 Preserved status and comments when reassigning review entries
* BWIPUAR-2536 Added perimeter display option in the Role Review follow-up page
* BWIPUAR-2554 Improved the Role Content Compliance Report
* BWIPUAR-2680 Added campaign names to default review completion emails
* BWIPUAR-2683 Added support for exporting the full campaign perimeter during campaign execution

#### Self-Managed

* BWIPUAR-2627 Updated batch log cleanup policy
* BWIPUAR-2563 Added support for redirecting the login page directly to a preconfigured IdP

#### SoD

* BWIPUAR-2417 Improved SoD dashboards and actionable remediation workflows

### Bug Fixes

#### Access360

* BWIPUAR-2541 Fixed an issue where campaign priority was not being displayed on the Access360 page

#### Dashboards

* BWIPUAR-2478 Fixed Correlation Outcomes displaying multiple repositories instead of a single repository
* BWIPUAR-2495 Fixed the out-of-the-box "abnormal login attempts" control field configuration for all repositories

#### Remediation

* BWIPUAR-2539 Fixed misleading default filters on the remediation management page
* BWIPUAR-2685 Fixed missing French translation/accent in the Remediation menu

#### Reviews

* BWIPUAR-2518 Fixed reviewer policy script issues for `groupowner` type
* BWIPUAR-2551 Fixed duplicate rows in role reviews when multiple tags were associated with the same permission
* BWIPUAR-2591 Added missing reviewer scripts for role reviews
* BWIPUAR-2611 Fixed missing custom campaigns in the custom management page
* BWIPUAR-2633 Fixed misleading error messages displayed when campaign saving failed
* BWIPUAR-2684 Fixed an issue where resetting entries from the campaign management page assigned the admin as reviewer
* BWIPUAR-2686 Fixed disabled reset buttons in the "Entries Signed Off" tab when accessed through links from the first tab
* BWIPUAR-2687 Enforced correct conditions for campaign status bulk reset buttons
* BWIPUAR-2692 Fixed data loading errors during the "Perimeter Preview" step of role review creation
* BWIPUAR-2729 Fixed an issue preventing review campaigns from being finalized after the starting timeslot was purged
* BWIPUAR-2723 Fixed a deadlock occurring during "Force All Bulk Reset" operations on the Entries Signed Off page

#### Self-Managed

* BWIPUAR-2601 Fixed inconsistent AI configuration flags (`aida.enabled` and `aiservice.enable`) that could break existing deployments
* BWIPUAR-2562 Fixed authenticated client access to `/ws` introduced in version 3.4.1
* BWIPUAR-2555 Fixed custom Keycloak themes hiding the IdP button

#### Other

* BWIPUAR-2574 Fixed purge failures caused by excessive parameters
* BWIPUAR-2580 Restored REST API compatibility after refactoring
* BWIPUAR-2584 Fixed portal crashes on the Identity Details page when job titles contained an ampersand (`&`)
* BWIPUAR-2603 Reduced excessive business view logs when filtering entries
* BWIPUAR-2690 Fixed incomplete column and attribute suggestions in views

### Security

#### Vulnerability Fixes

* BWIPUAR-2648 Fixed known vulnerabilities
